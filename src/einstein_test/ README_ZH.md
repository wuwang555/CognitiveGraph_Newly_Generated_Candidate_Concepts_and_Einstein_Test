# 爱因斯坦测试

## 一句话

把"相对论诞生前"的 44 个物理/数学概念喂给系统，看它能不能通过
四维概念空间中的迁移检测，把"相对性原理"和"张量分析/黎曼几何/
麦克斯韦方程"连接起来——这对应相对论的核心洞察。

## 概念集设计

**不含**："相对论"、"量子力学"、"量子场论"
**含**：所有爱因斯坦做出相对论所需的"原材料"

| 类别 | 概念 |
|------|------|
| 经典力学 | 牛顿定律、万有引力、力学、运动学、动量、能量守恒、摩擦力、刚体、振动、波 |
| 电磁学 | 静电力、电磁学、麦克斯韦方程、光速、以太、光学、声学 |
| 热力学 | 热力学、热传导、熵 |
| 流体/弹性 | 流体力学、弹性力学 |
| 数学 | 微积分、几何学、线性代数、微分方程、变分法、**张量分析**、**非欧几何**、**黎曼几何**、拓扑学、群论 |
| 时空/相对性 | **绝对时空**、**相对性原理**、惯性系、**伽利略变换**、坐标系、参考系 |
| 天文 | 天体力学、宇宙学、引力场 |
| 方法论 | **对称性**、守恒律、场 |

## 关注什么

跑完后，打开 `stage6_generative/candidate_migrations.csv`，看是否出现：

- `相对性原理 → (桥) → 麦克斯韦方程` → 狭义相对论的核心
- `相对性原理 → (桥) → 张量分析` → 广义相对论的语言
- `相对性原理 → (桥) → 黎曼几何` → 广义相对论的几何
- `绝对时空 → (桥) → 相对性原理` → 时空观的转变

**不要求全部出现**。只要出现一条，就说明"从原材料到洞察"这条路在
四维概念空间中是可观察的。
