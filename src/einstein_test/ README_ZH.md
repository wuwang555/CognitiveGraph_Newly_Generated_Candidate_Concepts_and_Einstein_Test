# 爱因斯坦测试

## 一句话

把“相对论诞生前”的 **82 个**物理/数学概念喂给系统，看它能不能通过
四维概念空间中的迁移检测，把“相对性原理”和“张量分析/黎曼几何/
麦克斯韦方程”连接起来——这对应相对论的核心洞察。

## 概念集设计

**不含**：“相对论”、“量子力学”、“量子场论”
**含**：所有爱因斯坦做出相对论所需的“原材料”，共 **82 个**概念，
分属 8 个域。

| 域 | 数量 | 概念 |
|----|------|------|
| 经典力学 | 22 | 牛顿定律、万有引力、力学、运动学、动量、能量守恒、摩擦力、刚体、振动、波、惯性、加速度、功、功率、角动量、开普勒定律、潮汐力、离心力、科里奥利力、速度、惯性质量、引力质量 |
| 电磁学 | 15 | 静电力、电磁学、麦克斯韦方程、光速、以太、光学、声学、电场、磁场、电势、电感、电容、电磁波、光的干涉、光的衍射 |
| 热力学 | 9 | 热力学、热传导、熵、温度、热量、理想气体、热机、卡诺循环、热辐射 |
| 流体/弹性 | 2 | 流体力学、弹性力学 |
| 数学 | 17 | 微积分、几何学、线性代数、微分方程、变分法、**张量分析**、**非欧几何**、**黎曼几何**、拓扑学、群论、偏微分方程、球谐函数、复变函数、傅里叶变换、微分几何、向量分析、概率论 |
| 时空/相对性 | 10 | **绝对时空**、**相对性原理**、惯性系、**伽利略变换**、坐标系、参考系、同时性、时间、空间、长度 |

| 方法论 | 4 | **对称性**、守恒律、场、**协变** |

**加粗**的是与相对论洞察直接相关的关键原材料：张量分析、非欧几何、
黎曼几何、绝对时空、相对性原理、伽利略变换、对称性、协变。

**域划分说明**：概念集按 `EINSTEIN_DOMAINS` 划分为 8 个域。
方法论域在代码中命名为 `principles`，以享受原论文的“跨域 0.6”
偏好；这不影响概念本身，只影响建图时的跨域边权。

## 关注什么

跑完后，打开 `stage6_generative/candidate_migrations.csv`，看是否出现：

- `相对性原理 → (桥) → 麦克斯韦方程` → 狭义相对论的核心
- `相对性原理 → (桥) → 张量分析` → 广义相对论的语言
- `相对性原理 → (桥) → 黎曼几何` → 广义相对论的几何
- `绝对时空 → (桥) → 相对性原理` → 时空观的转变

**不要求全部出现**。只要出现一条，就说明“从原材料到洞察”这条路在
四维概念空间中是可观察的。

**补充读法**：

- `candidate_migrations.csv` 的每一行是 `start, via, end, direct_distance,
  path_distance, improvement`。`improvement` 越大，说明这条迁移路径
  比直接连接“省”得越多，即桥接节点（`via`）的结构作用越强。
- `candidate_compressions.csv` 给出的是压缩候选（`center, cluster, size,
  phi`），可以用来观察“相对性原理”“绝对时空”“张量分析”等关键概念
  是否作为压缩中心或簇成员出现。
- `stage3_fixpoints/fixpoints.json` 给出不动点 A/B/C 的结构化定义。
  对方法 A：`size=1` 是原子不动点候选，`size>1` 是原始事件层的高频
  整体候选；`size≥2` 项集带 `phi`。对方法 B/C：`minsize=1` 下通常
  输出 size=1 的单概念候选，`phi=null`。

## 输出

```
results/einstein_test/
├── stage1_universe/    原始压缩事件 + 能量摘要
├── stage2_graph/       压缩关联图 G2
├── stage3_fixpoints/   不动点 A/B/C + 结构化定义
├── stage4_g1/          G1 能量图导出
├── stage5_four_dim/    四维概念空间 + PCA
├── stage6_generative/  生成图 + 压缩/迁移候选
└── einstein_test_summary.json
```

**各 stage 对应本仓库的六环逻辑链**：

| stage | 对应环节 | 主要输出 |
|-------|---------|---------|
| `stage1_universe/` | 一阶系统演化 | `raw_compression_events.csv`、能量摘要 |
| `stage2_graph/` | 第 1 环 G2 关系图 | `compression_edges.csv`、图统计 |
| `stage3_fixpoints/` | 第 4 环不动点 | `fixpoints.json`、`concept_structure.json` |
| `stage4_g1/` | 第 5 环 G1 导出 | `g1_nodes.csv`、`g1_edges.csv`、`energy_history.csv` |
| `stage5_four_dim/` | 第 5 环四维空间 | `scale{N}.csv`、`scale{N}_pca.csv` |
| `stage6_generative/` | 降层级输入端的生成图 | `candidate_compressions.csv`、`candidate_migrations.csv` |

**注意**：`stage6_generative/` 的“生成图”是本仓库范围内基于不动点
构建的观察图，用于检测压缩/迁移候选。它不是另一个项目里的“概念生成
图构造与降层级再压缩/迁移”——本仓库只做“抓重点”，不做概念生成。

## 跑法

```bash
cd src/einstein_test

```

## 概念集来源

概念定义见 `concepts_einstein.py` 的 `EINSTEIN_CONCEPTS`（82 个概念），
域划分见 `EINSTEIN_DOMAINS`（8 个域），元结构见 `EINSTEIN_META`
（10 个元结构：结构、运动、能量、力、抽象、介质、天体、场、量、时空）。

**设计原则**（来自 `concepts_einstein.py` ）：

- 每条定义一句话、自然、不堆砌桥接词；
- 用物理/数学的“基本词汇”（力、运动、场、空间、时间、定律、守恒、
  对称、变换、度规、几何、坐标、参考系）；
- 让 jieba 自然切出共享词，而不是人工塞；
- 方法论域改名为 `principles`，以享受原论文的“跨域 0.6”偏好。
