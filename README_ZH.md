# README — 认知图项目的三个下游模块

> 本文档描述建立在原论文（《认知的几何、代数与动力学》）两个公设之上的三个下游模块：**生成图**（候选新概念）、**爱因斯坦测试**（从原材料中发现洞察的可发现性）以及**自我反思循环**（反馈下的自我修改）。
>
> 整体立场与主项目完全一致：**不追求拟合，只追求可算**。每个模块都清楚说明它做什么、观察到什么，并在结论处标明边界。

---

## 0. 共同基础：三个模块共享什么

三个模块都建立在同一条上游流水线之上，该流水线已在主项目中实现，且**不得修改**：

```
G1  认知能量图
    ↓ 自发压缩事件
G2  无向加权共现图
    ↓ 不动点检测（方法 A / B / C）
不动点  (core / boundary / logic / energy)
    ↓ 映射
四维连续空间  (b, c, g1, g2)
```

三个模块都不引入新公设。所有阈值都是绝对值，因此规模之间保持可比。每个候选都是候选，不是已验证的概念。三个模块的区别仅在于**它们如何处理不动点和四维坐标**：

| 模块 | 从共享层获得的输入 | 它做什么 | 它产出什么 |
|---|---|---|---|
| **生成图** | 不动点（B 或 C）、四维坐标、G2 边 | 演化一张稀疏图，节点为不动点，边权为四维欧氏距离；检测压缩与迁移 | **候选新概念**（不动点的簇与路径） |
| **爱因斯坦测试** | 82 个相对论前概念、完整流水线 | 检验迁移检测能否将“相对性原理”与张量分析 / 黎曼几何 / 麦克斯韦方程连接起来 | **洞察链可从原材料中被发现的证据** |
| **自我反思循环** | G3 结果（来自生成图的簇 + 迁移） | 抽象反馈规则 K，并将其写回 G1 的能量公式、遍历偏好和检测判据；迭代 | **系统在自我反馈下如何漂移的观察** |

三个模块都是“抓重点”的*下游*。它们**不是**主仓库“抓重点”层的一部分，也**不声称生成已验证的新概念**。它们生成的是候选结构，其含义需要事后解读。

## 1. 生成图 — 候选新概念

### 1.1 它是什么

生成图将**不动点作为节点**，使用 **G2 共现边作为图结构**，并使用**四维欧氏距离作为边权**：

```
d_ij = sqrt( Δb² + Δc_norm² + Δg1_norm² + Δg2_norm² )
```

然后在这张图上运行原论文的演化与压缩/迁移检测。用原论文的语言来说：

| 原论文 | 生成图 |
|---|---|
| 全连接能量图 | 不动点上的稀疏共现图 |
| `E_ij = α(1−sim) + β/(1+H) + γ·div` | `E_ij = d_ij`（四维距离） |
| 能量下降 | 距离下降 |
| 压缩 `Φ = 内部 / 外部` | 压缩 `Φ = 外部距离 / 内部距离` |
| 迁移 `E_az + E_zb < E_ab − Δ` | 迁移 `d_az + d_zb < d_ab × (1−ε)` |

### 1.2 为什么用不动点而非原始概念

原始概念是 G1 中的一个节点。不动点是系统反复压缩的**稳定单元**。当若干不动点在生成图上通过压缩或迁移连接起来时，所得的簇或路径就是我们所说的**候选新概念**：

- 它的**核心**是由压缩或迁移连接起来的不动点集合；
- 它的**边界**是各不动点自身边界的并集，按不动点分别保留（同一个边界概念对不同不动点可能携带不同的 `logic` 权重——我们不合并它们）；
- 它的**逻辑**是各不动点的 `logic` 强度，保留为二分结构 `(边界概念, 不动点) → 强度`；
- 它的**描述**不是系统的一个动作，而是定义形式的一个属性：一旦核心 / 边界 / 逻辑被记录下来，描述就自动存在。

### 1.3 它**不**做什么

- 它**不**声称以“向 G1 添加新节点”的意义“生成概念”。候选簇和路径是**在现有不动点之上观察到的结构**，不是反馈回一阶系统的新单元。
- 它**不**按外部语义标准筛选候选。候选就是候选；它是否“有意义”是下游判断，不是图的属性。
- 它**不**合并按不动点分别保留的边界结构。候选的边界是一个二分对象，不是一个扁平集合。

### 1.4 入口与输出

```
src/generative_graph/
    build_graph.py      构建稀疏四维距离图
    evolve.py           运行原论文的演化
    detect.py           压缩与迁移检测
    run_generative.py   端到端入口
```

输出（按 config、按 scale、按不动点方法）：

```
results/generative_graph/config_{X}/pool_{P}/scale{N}/
    graph_nodes.csv
    graph_edges.csv
    energy_history.csv
    traversal_history.csv
    candidate_compressions.csv
    candidate_migrations.csv
    info.json
results/generative_graph/summary.csv
```

## 2. 爱因斯坦测试 — 从原材料中发现洞察的可发现性

### 2.1 它是什么

爱因斯坦测试提出一个狭窄、可证伪的问题：

> 仅给定**相对论诞生之前**可用的概念原材料，四维概念空间中的迁移检测能否将“相对性原理”与张量分析 / 黎曼几何 / 麦克斯韦方程连接起来？

概念集包含来自 8 个域（经典力学、电磁学、热力学、流体/弹性、数学、时空/相对性、天文学、原理）的 **82 个概念**，并明确**排除**“相对论”“量子力学”和“量子场论”。

测试寻找如下形式的迁移：

- `相对性原理 → (桥) → 麦克斯韦方程`（狭义相对论）
- `相对性原理 → (桥) → 张量分析`（广义相对论的语言）
- `相对性原理 → (桥) → 黎曼几何`（广义相对论的几何）
- `绝对时空 → (桥) → 相对性原理`（时空观的转变）

**不要求四条全部出现。** 只要出现一条，就足以表明“从原材料到洞察”在四维概念空间中是可观察的。

### 2.2 “成功”意味着什么、不意味着什么

- **成功**意味着：一条形状正确的链可从原材料中被发现。它**不**意味着系统“发明了相对论”。系统没有触发词、没有历史语境、没有实验约束。
- **部分成功也是成功。** 如果爱因斯坦推理链的第 4–7 步被遍历到，但第 1–3 步缺失，这仍然是一个正面结果：它展示了*在不完整初始条件下的结构可发现性*。
- **失败是有信息量的。** 如果没有链出现，这意味着按当前编码的原材料在当前距离度量下不支持该链。这是关于编码的一个观察，不是对原论文的反驳。

### 2.3 入口与输出

```
src/einstein_test/
    concepts_einstein.py   82 个概念、8 个域、元结构
    run_all.py             端到端入口
```

输出：

```
results/einstein_test/
    stage1_universe/       原始压缩事件 + 能量摘要
    stage2_graph/          G2 共现图
    stage3_fixpoints/      不动点 A/B/C + 结构化定义
    stage4_g1/             G1 能量图导出
    stage5_four_dim/       四维空间 + PCA
    stage6_generative/     生成图 + 压缩/迁移候选
    einstein_test_summary.json
```

阶段编号对应主项目的六环逻辑链，因此爱因斯坦测试可以读作“同一条流水线，运行在一个刻意受限的概念集上”。

## 3. 自我反思循环 — 反馈下的自我修改

### 3.1 它是什么

自我反思循环是唯一**修改一阶系统**的模块。它以严格受限的方式进行：

```
G1 → G2 → 不动点 → 四维 → 生成图 → G3（簇 + 迁移）
    ↑                                                   │
    └────── 反馈 K（边增强、偏好路径） ──────────────────┘
```

每一轮：

1. 运行 G1 固定次数的迭代（`interval_iterations`）。
2. 构建 G2、检测不动点、映射到四维、构建生成图，并检测压缩与迁移（**G3**）。
3. 从 G3 抽象出反馈规则集 **K**：
   - `edge_boosts`：对于每一对在高 Φ 簇或高改善迁移中共同出现的概念，给予额外的学习率乘子 `(1 + δ)`。
   - `preferred_paths`：实际的高改善路径，用于在遍历时偏置邻居选择。
   - `cluster_patterns`：高 Φ 簇，用于给未来的压缩事件打上 `g3_matched` 标记。
4. 将 K 写回 G1：
   - `record_edge_activation`：学习率 × `(1 + boost)`。
   - `_random_traversal`：邻居选择按 `(1 / weight) × (1 + boost)` 加权。
   - `_detect_emergence`：匹配的事件获得 `g3_matched` 标记。
5. 从保存的 G1 状态继续下一轮。

### 3.2 “自我修改”改变了什么——以及没有改变什么

**它改变了连接层。** 反馈作用于边权、遍历偏好和检测标记。这是决定*系统如何在不动点之间行走*的层。

**它不改变判据层。** 两个公设、所有阈值（`lattice_min_support`、`role_min_stability`、`compression_phi_threshold`、`migration_epsilon` 等）以及所有检测规则保持固定。系统不会在不同轮次之间对“什么算作不动点”做出不同决定。

**它不改变成员层。** 在观察到的五轮运行中，B 保持在 33–34 个成员，C 保持在 19–20 个。只有一个概念（`注意力机制`）在第 4 轮进入并保持；一个概念（`生成对抗网络`）在第 3 轮退出 C，在第 4 轮回归。核心成员基本稳定。

因此，自我修改**不是**“系统学习了新概念”。而是“系统学习了现有稳定单元之间的*新路线*”。

### 3.3 五轮运行显示了什么

这一观察最好描述为**漂移**，而不是“改善”或“退化”。有三个事实很突出：

1. **漂移有方向。** 在五轮中，路径层从 CS 基础设施枢纽（物联网、信息安全、算法）转向 AI / 软件工程 / 编译器 / NLP 枢纽。物理轴始终存在，并在第 5 轮回摆到头部。这是*有方向的*漂移，不是随机噪声。
2. **漂移有结构。** 改善分布的头部并未单调上升；中间带（0.1–0.3）的路径数量持续增长，而头部在第 2 轮附近达到峰值。漂移拓宽的是*中部*，不是*头部*。
3. **漂移不会失控。** `raw_compressions` 保持在 1184–1265（±6.8%）；`edge_boosts` 保持在 202–215；`preferred_paths` 保持在 193–227。反馈规则集 K 是**每轮重新计算，而非累积**，这防止系统锁定到一小撮边上。

### 3.4 关于“正确性”——没有外部检验

这是自我反思循环最重要的边界。

- 系统**没有外部语义检验**。没有奖励函数、没有标注数据、没有下游任务准确率。没有“正确答案”可以用来比较漂移。
- 系统**确实**拥有的是**内部一致性**：K 从 G3 抽象而来，而 G3 的 `improvement` 是用系统自身的四维距离定义的。被增强的边是上一轮 G3 在当前度量下认为“能量更省”的边。
- 因此，漂移是**自洽的方向性漂移**，不是随机噪声，也不是已验证的改善。这一区分很重要：*自洽*不意味着*正确*；它意味着漂移是由系统自身的判据组织起来的，而不是由外部监督组织起来的。

任何关于漂移是否“好”的陈述都属于另一种探究——LLM 奖励函数、人类语义审阅或下游任务评估。那些是*外部*检验，本模块刻意不执行它们。

## 4. 三个模块如何关联

```
                          ┌─────────────────────────┐
                          │  爱因斯坦测试            │
                          │  （82 个原始概念）       │
                          │  问：洞察链能否从原材料  │
                          │  中被发现？              │
                          └───────────┬─────────────┘
                                      │ 同一条流水线
                                      ▼
主项目 ──► G1 ──► G2 ──► 不动点 ──► 四维
                                      │
                                      ▼
                          ┌─────────────────────────┐
                          │  生成图                  │
                          │  （不动点作为节点）      │
                          │  问：哪些不动点簇 / 路径 │
                          │  是候选新概念？          │
                          └───────────┬─────────────┘
                                      │ G3：簇 + 迁移
                                      ▼
                          ┌─────────────────────────┐
                          │  自我反思循环            │
                          │  问：当系统自身的 G3     │
                          │  被反馈回去时，系统如何  │
                          │  漂移？                  │
                          └─────────────────────────┘
```

- **生成图**是*观察层*：它读取不动点和四维坐标，并产出候选结构。
- **爱因斯坦测试**是*可发现性层*：它将同一条流水线应用于一个刻意受限的概念集，并追问一条已知的洞察链是否在结构上可被发现。
- **自我反思循环**是*反馈层*：它消费 G3 并将 K 写回 G1，产出一系列轮次，其漂移可以被描述。

三个模块共享相同的设计立场：

- **不引入新公设。** 原论文的两条公理仍然是唯一的驱动力。
- **不改变绝对阈值。** 每个模块使用相同的绝对阈值，以便规模之间保持可比。
- **不声称已验证的概念。** 产出的一切都是*候选*。验证（如果发生）是外部的。
- **不拟合。** 目标是构建一个可计算的系统，并观察它做什么。

## 6. 边界——每段一个

**生成图。** 它产出的簇和路径是候选新概念，不是已验证的概念，也不是 G1 中的新节点。候选的边界是按不动点分别保留的二分结构，不是扁平集合。候选是否有意义是下游判断。

**爱因斯坦测试。** 该测试不声称系统“发明了相对论”。它声称一条形状正确的链在当前距离度量下从原材料中*在结构上可被发现*。部分成功（第 4–7 步被遍历，第 1–3 步缺失）仍然是正面结果。失败是关于编码的一个观察，不是反驳。

**自我反思循环。** 系统改变的是它的*连接层*，不是它的*判据层*或*成员层*。没有外部检验；漂移是*自洽的*方向性漂移，不是已验证的改善。任何关于漂移“好”或“坏”的判断都属于外部检验（奖励函数、人类审阅、下游任务），本模块刻意不执行它们。

## 7. 一句话总结

**生成图通过在四维距离图上连接不动点来产出候选新概念；爱因斯坦测试检验一条已知的洞察链能否从受限的原材料中在结构上被发现；自我反思循环将 G3 反馈回 G1，并观察系统如何漂移。三个模块共享相同的两个公设、相同的绝对阈值和相同的立场：不拟合，不声称已验证的概念，只做有明确边界的可算观察。自我反思循环所展示的是：在自我反馈下，系统以一种有方向、有结构的方式漂移，而不会失控——这是一种自洽的方向性漂移，不是已验证的改善。**
